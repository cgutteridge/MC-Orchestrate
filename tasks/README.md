# Tasks Folder

This folder stores detailed backlog specs so `TASKS.md` can stay short and easy to scan during coding turns.

## Documents

- `phase-1-foundations.md`
  - DIG schema/revisioning, deterministic compiler flow, material KB and palette resolver, planner guardrails, follow-up context reliability, and Azure baseline validation.
- `phase-2-terrain-blending.md`
  - Terrain context cards, terrain-adaptive compile transforms, and placement/anchoring mode expansion.
- `phase-3-retrieval-refinement-undo.md`
  - Retrieval layer, bounded refinement loop, transaction/undo model, and execution UX/job control.
- `world-mutation-path.md`
  - Current world-mutation path audit and migration decision criteria for plugin API execution.
- `open-questions.md`
  - Research-blocking decisions and operational unknowns to resolve before deeper architecture work.

## Usage

- Keep active priorities in `TASKS.md`.
- Put execution details, acceptance criteria, and rollback plans in phase docs.
- When a phase task completes, move it to `TASKS.md` `Done` with date and evidence, then update the relevant phase doc.
